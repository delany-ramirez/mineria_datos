# Minería de Datos (EACD)

Este repositorio contiene el material del curso de Minería de Datos, enfocado en las técnicas de extracción de conocimiento y análisis predictivo.

## 🎯 Objetivo del Curso

El objetivo principal es capacitar a los estudiantes en el proceso de descubrimiento de conocimiento en bases de datos (KDD), abarcando desde la adquisición y limpieza de datos hasta la implementación y evaluación de modelos de aprendizaje automático.

Al finalizar el curso, el estudiante será capaz de:
- Preprocesar y transformar datos para su análisis.
- Aplicar algoritmos de agrupamiento (clustering) y asociación.
- Desarrollar modelos predictivos de clasificación y regresión.
- Evaluar la calidad y el rendimiento de los modelos obtenidos.

## 📂 Estructura del Repositorio

- **`data/`**: Conjuntos de datos utilizados en las prácticas y ejemplos.
- **`docs/`**: Documentación complementaria, guías de instalación y tutoriales.
- **`lectures/`**: Material teórico, presentaciones y notas de clase.
- **`notebooks/`**: Cuadernos interactivos (Jupyter) con implementaciones prácticas.
- **`projects/`**: Guías y enunciados para los proyectos del curso.
- **`src/`**: Scripts de Python y código fuente reutilizable.

## 🛠️ Configuración del Entorno

Para este curso, recomendamos utilizar **uv** como gestor de paquetes y entornos virtuales debido a su alta velocidad y confiabilidad.

Puedes encontrar una guía detallada en: [`docs/tutorial-uv.md`](docs/tutorial-uv.md)
