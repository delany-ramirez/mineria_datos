# Sesión 1: Taller Práctico - Saber PRO

## 🎯 Objetivos del Taller
Familiarizarse con la carga, inspección y combinación de datasets en Python utilizando **Pandas**.

## Actividades Principales:
1. **Carga e Inspección:** Cargar datasets y realizar una inspección inicial de tipos y valores.
2. **Limpieza:** Aplicar técnicas de limpieza (manejo de faltantes y duplicados).
3. **Transformación:** Aplicar métodos de imputación, estandarización y codificación.
4. **Análisis:** Realizar un análisis exploratorio inicial para detectar patrones.

---
*Este taller utiliza datos reales de las pruebas Saber PRO para aplicar los conceptos de limpieza e ingeniería de características.*
